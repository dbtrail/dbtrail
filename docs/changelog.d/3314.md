- **PostgreSQL port: a connection with no source refuses a value cast to char(n) or `"char"`** (#3314). On a server that sends nothing to its source, the copy answered `'abc'::"char"` as `abc` and `'a '::char(3) = 'a'` as false, where PostgreSQL answers `a` and true. Such a statement is now refused (0A000) rather than answered otherwise. A server that can reach its source already sent every cast there. Closes #3233: a domain over char(n), over numeric or over another domain was already the source's wherever a statement reads it (#3249).
