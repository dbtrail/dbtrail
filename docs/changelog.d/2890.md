- **Packages: the PostgreSQL port has a service of its own** (#2890, closes #2774). The `bintrail-console` deb and rpm install a third unit, `bintrail-pg-router`, which answers the PostgreSQL port (5433) where PostgreSQL clients read the copy of a PostgreSQL server. The package enables and starts it once, as it does the router; it accepts no connection until the port for SQL clients is turned on, and with MySQL or MariaDB servers it waits and uses next to nothing. Its settings (where it listens, a certificate, its size) are at the end of `/etc/bintrail/bintrail-console.env`, commented out. On a machine that runs a second PostgreSQL cluster, 5433 is often that cluster's: set `BINTRAIL_PG_ROUTER_LISTEN` to another port. To stop the service for good: `sudo systemctl disable --now bintrail-pg-router`.
