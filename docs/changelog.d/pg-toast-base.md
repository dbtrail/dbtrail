- **PostgreSQL: a large value an UPDATE left as it was is read from the table's copy when no change holds it** (part of #2775). Nothing captures such a change yet. A snapshot update of a table that is not at `REPLICA IDENTITY FULL` now reads, from the row its previous file holds, a large value that an UPDATE did not touch and no change since that file carries. One read of the file's key columns, only when a table has such values. A row the file does not hold is refused by name.
