- **PostgreSQL: a views file that cannot read a table's delta refuses, and no longer reads the file alone** (part of #2757). A views file that follows later snapshots, names its files in S3, or carries relative paths cannot look beside a table's file when it is written. For a PostgreSQL table published as its previous file and a delta (`BINTRAIL_PG_TABLE_DELTAS`, off by default), it read the file alone: the table as it was at an earlier update. Such a view now asks, when it is read, whether a delta sits beside the file, and refuses with what to do if one does. With the switch off no delta exists and these views answer as before; MySQL and MariaDB views are unchanged.
