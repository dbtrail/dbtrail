- **PostgreSQL port: `SHOW dbtrail.router_status` says which side answered and why** (#3034, part of #3021). On any connection to port 5433 the statement answers name and value rows: the server, whether statements may go to the source (`forwarding`), the newest snapshot and its age, and for the connection's last statement who answered it (`last_answer`: `copy`, `source`, `refused`, or `none`), why (`last_answer_reason`, and the same in a sentence), whether the client got an error, and how old the data of a copy's answer was. The server's counts follow, the ones `/status` serves. The port answers it itself in every state of the connection, a failed transaction block included, never sends it to the source or the copy, and does not count it as an answer. `SHOW ROUTER STATUS`, the MySQL port's spelling, used to come back from the source as a syntax error; it now answers with the statement to send.
