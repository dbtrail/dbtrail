- **PostgreSQL: the tail of a table's recent changes, not in use yet** (part of #2756). Fresh mode lays the changes captured since the last snapshot over the copy, and for a PostgreSQL source every table is refused. This adds the part that holds a PostgreSQL table's newest change per key and writes it as the small files the views read: text columns from the snapshot's recorded shape, changes ordered by commit LSN, text keys. Nothing builds one yet, so a PostgreSQL copy still answers as of its last update.
