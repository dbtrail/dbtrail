- **A PostgreSQL server can be added from the terminal** (#2894, part of #2773). `dbtrail server add --flavor postgres -h <host> -u <user> -p -d <database> --publication <name>` checks a PostgreSQL and starts recording it, as `+ Add server` does in the web interface; until now the command answered that a PostgreSQL is added in the web interface. The replication slot is created for you (`bintrail_<database>`, or `--slot`); the publication is the one you created. On a terminal, what you leave out is asked for. At the end it prints the `psql` line for the PostgreSQL port. `--flavor postgres` has to be said, and port 5432 without it stops with what to add.
