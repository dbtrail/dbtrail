- **PostgreSQL: a server with no changes no longer ends in a full read of the source** (#2889). Each snapshot records from when the changes it is missing begin, and the next update reads the index from there. On a source with no change that moment never moved; once the index had rotated past it, the update was refused and DBTrail read the whole database again, every time the server sat idle for longer than the index keeps its changes. The moment now follows when capture was last caught up with the source, so an idle server's snapshot stays updatable. An index whose capture never recorded that (an older one) behaves as before.
