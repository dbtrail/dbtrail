- **PostgreSQL: a views file that follows later snapshots reads a table's delta instead of refusing it** (#3195). The `views.sql` the console downloads, and `bintrail views` without `--pin-snapshot`, follow the `current` pointer or the newest snapshot. For a PostgreSQL table with a table delta beside its file (`BINTRAIL_PG_TABLE_DELTAS`), such a file refused the table when it was read. It now reads the file and every pair beside it, one or a chain, the way a MySQL table's following view reads its chain, and the file alone when there is none. Two tables keep the refusal, as they do for MySQL: one with a column a table delta reserves, and one with another table in its schema named `<table>.<anything>`. Pinned views and MySQL views are unchanged.
