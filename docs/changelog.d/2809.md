- **Engine Routing answers `TIMESTAMPDIFF` on the copy** (#2611). `WHERE TIMESTAMPDIFF(DAY, created_at, NOW()) > 30` went to MySQL every time: the copy has no `TIMESTAMPDIFF`, and its `date_diff` counts the boundaries a unit crosses, where MySQL counts whole units (January 31 to February 28 is no month). The routing port now sends it as a function of the copy's session that counts as MySQL does, for every unit from `MICROSECOND` to `YEAR`, when each date is a `DATE` column, a `DATETIME` or `TIMESTAMP` column without fractional seconds (a `TIMESTAMP` under UTC or a fixed offset), `NOW()`, `CURDATE()`, `UTC_TIMESTAMP()`, `UTC_DATE()` or `CURRENT_TIMESTAMP`. Text, a literal, a placeholder, a fraction, `SQL_TSI_` units and arithmetic on the result stay on MySQL. A statement that calls one of the copy's own `_bintrail_` functions by name now stays on MySQL too, which refuses it. The port without routing is unchanged. See [date functions under routing](time-travel-sql.md).
