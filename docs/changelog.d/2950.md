### Added

- **`dbtrail config show`** (#2671). It lists every setting that has a value, with the value and where it comes from: the environment, an env file (`.bintrail.env` or `config.env`), or a line of `/etc/dbtrail/dbtrail.cnf`. A setting listed as a secret is never printed, nor any other value that looks like it carries a login or a token. It also names `BINTRAIL_` variables no program reads (a typo, most likely) and the ones that no longer do anything. `--all` also lists the settings with no value.
