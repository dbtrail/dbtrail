- **PostgreSQL: the console's recover no longer skips an UPDATE whose changed columns are unknown** (#3005). With a changed-column filter on a PostgreSQL index, an UPDATE of a table that was not at REPLICA IDENTITY FULL (only the earlier row's key captured, so which columns changed is unknown) was left out of the script without a word. It is now included, and the recover refuses the window, because that change cannot be undone. MySQL is unchanged.
