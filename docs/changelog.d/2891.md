- **PostgreSQL capture records the source's own time when it was last caught up** (#2891). The index gains a column (`stream_state.pg_caught_up_source_at`, added when capture starts): the source's clock at the moment capture last had everything the source had; on a standby, the commit time of the last transaction it had replayed. Nothing changes for you yet: it is what lets a later change keep an idle PostgreSQL server's snapshot updatable without mistaking a standby that replays late for one that is up to date.
