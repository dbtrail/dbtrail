- **A table added to a PostgreSQL publication after a snapshot is brought into the copy** (#2759). A snapshot update of a PostgreSQL server did not look for tables its snapshot lacks, so a table added to the publication stayed out of the copy until someone read the source in full. The update now asks the source which tables the publication holds, names the ones it left out on the Snapshots page, and the schedule takes one full read to include them, by the rules a MySQL source already follows: only where the schedule may take full reads, and a limited number of times for the same tables.
