- **The `dbtrail` command of a Docker install suggests commands that run** (#3015). It told the program inside the container to call itself `dbtrail`, so `server add` ended with `Next ... dbtrail snapshot run shop`, which is command not found until the file is linked into a folder of the PATH. It now says `dbtrail` only when that word runs it, and its absolute path otherwise (a space escaped with a backslash), in the help and in every command it names next.
