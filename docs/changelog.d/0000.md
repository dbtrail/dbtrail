- **PostgreSQL port: fixes from a review of the wire port**. A binary timestamp parameter more than about 292 years from 2000 is decoded to its own date (it was wrapped to a wrong one with no error). Catalog LIKE patterns are read by character, so `'café'` finds `café` and `caf\é` no longer crashes the connection. The screen in front of the source refuses `U&'...'` and `U&"..."` only where `U&` starts a token, so `SELECT menu&4` is sent again. The comparison tool reads a function written as a quoted name (`"pg_sleep"(50)`) as the function, reads nested block comments as PostgreSQL does (`/* /* */ SELECT */ DELETE` is a DELETE), and no longer files a difference as a live write when its second read of the source was cut at the row limit. An Execute of `SHOW` ends with the tag `SHOW` instead of `SHOW 1`, and the `options` start-up parameter turns dashes into underscores after `-c` and refuses `--name` with no value, as PostgreSQL does.
