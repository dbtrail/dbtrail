- **PostgreSQL fresh mode: the newest changes of a table take about half the memory** (#2775). A table's tail held every changed row as the map its change arrived with, which for a row of a hundred bytes was most of the 1.6 KB a changed row cost. On a source written to all the time the tails passed their memory budget minutes after each snapshot update, stopped advancing, and statements were answered as of the snapshot. Each row is now held as one run of bytes.
