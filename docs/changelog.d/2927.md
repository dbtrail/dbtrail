- **PostgreSQL capture records which event its saved position reaches** (part of #2756). The index gains a column, `stream_state.pg_checkpoint_event_id`, added when the index is opened by this version: the newest event at or before the position a PostgreSQL capture saved, written when a transaction ended. A reader that must stop at whole transactions uses it: after a restart PostgreSQL sends the last saved transaction again, and its rows stay above this event until that delivery is whole. A MySQL or MariaDB capture leaves the column empty.
