- **The web interface's .sql download works for a PostgreSQL server** (#3157). **Build a .sql backup for any moment** always asked for a mydumper-format dump, which cannot hold a PostgreSQL table, so on a PostgreSQL server every build failed with a message that named options of the terminal command (`--output-format parquet`, `--output-format psql`). The build of a PostgreSQL server now writes one `<schema>.<table>.sql` file per table, the files `bintrail-pg reconstruct --output-format psql` writes, and the download is one `.tar.gz` of them; load each with `psql -v ON_ERROR_STOP=1 -f <file>`. The card says "To load into PostgreSQL" on such a server. MySQL and MariaDB servers build a mydumper-format dump as before.
