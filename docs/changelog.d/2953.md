### Changed

- **The web interface says where a value DBTrail started with is set** (#2671). Where a setting is locked by where DBTrail starts (SQL memory, telemetry, the routers' own SQL mode), a line of `/etc/dbtrail/dbtrail.cnf` or an env file is named. For index rotation and the backup settings, where a value saved in the web interface wins, each says what it is used instead of and where that is set. `dbtrail config check` reports a line of the file that such a saved value overrides, says which server list it compared with (`--servers-file` names another), and says when it could not compare.
