- **PostgreSQL is no longer labelled beta** (#3056). The README, `docs/postgres.md`, `docs/SUPPORT.md`, `docs/install.md`, `docs/guide.md` and the description of the `bintrail-pg` package drop the label; the limits they list stay as they were. A single-row `reconstruct` no longer prints the warning that said container types "remain beta" on every run against a PostgreSQL source. Which types are validated through that path and which are untested is in [PostgreSQL source](postgres.md#querying-and-recovering). The warning about a snapshot written under different rendering settings is still printed.
