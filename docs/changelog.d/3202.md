- **PostgreSQL docs: what the port cannot see when capture stops saving its state** (#3202). The port takes a table's copy as current from the capture's record of dropped changes, saved with each checkpoint. `docs/postgres.md` now says that a capture which saved its state and then cannot save it again leaves later drops unrecorded, so the port can keep answering that table from its copy with no notice. Docs only; the fix is tracked in the issue.
