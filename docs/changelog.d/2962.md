- **PostgreSQL: fresh mode no longer falls back to the snapshot each time a table is written again** (#2775). A snapshot update writes a changed PostgreSQL table again, and the recent changes laid over it were read again from nothing each time. Until they were in, a statement waited 3 seconds and then answered from the new snapshot alone, which is as old as the update took: minutes on a large database, with a NOTICE, and a value older than one the same connection had just read. The changes already held are now kept and trimmed to the new snapshot, as they are for MySQL. A table the update left as it was, and an update on a source with no change after it, still go the old way.
