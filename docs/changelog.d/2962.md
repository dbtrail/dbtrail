- **PostgreSQL: fresh mode no longer falls back to the snapshot at every snapshot update** (#2775). A PostgreSQL table is written again at each update, and the recent changes laid over it were read again from nothing each time. Until they were in, a statement waited 3 seconds and then answered from the new snapshot alone, which is as old as the update took: minutes on a large database, with a NOTICE, and a value older than one the same connection had just read. The changes already held are now kept and trimmed to the new snapshot, as they are for MySQL.
