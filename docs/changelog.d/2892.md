- **PostgreSQL: the guide says what a very large transaction costs** (#2892, closes #2764). PostgreSQL sends a transaction to capture only once it has committed, whole, and the changes committed after it wait behind it: a transaction that changed millions of rows can leave the copy minutes behind, however briefly it was open, and one open for an hour that changed ten rows costs nothing. docs/postgres.md now says so, and the capture status shown while the copy is behind mentions it. Committing bulk changes in batches keeps the copy close.
