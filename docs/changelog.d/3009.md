- **PostgreSQL: a large value an UPDATE left as it was is read from the table's copy when no change holds it** (#3009, part of #2775). Nothing captures such a change yet. A snapshot update of a table that is not at `REPLICA IDENTITY FULL` now reads, from the row its previous file holds, a large value that an UPDATE did not touch and no change since that file carries: one read of the file's key columns and one of that column for the rows found, only when a table has such values. It refuses by name, and never writes a NULL, when the file has no row under the key, holds a NULL or an empty text there, was written over changes capture lost, or is a full read newer than the changes in hand; and in a run told to go on over missing changes.
