- **A `--since` or `--until` written with a UTC offset no longer reads as a range with no data.** `bintrail recover --since 2026-11-20T10:00:00-05:00` refused with every hour of its range reported as rotated and not archived, and `query`, the web interface and the MCP tools warned of hours with no data that the index held. The planner looked each hour up among the index's hours, which are in UTC, without bringing the range to UTC first. No answer was wrong; a valid recovery was refused.
- **An event in the same second as the schema snapshot is no longer taken for one older than it.** A binlog event carries its second and no fraction, so one written just after the snapshot could count as before it and be read under the snapshot's column names with a warning where a changed table is a hard error.
