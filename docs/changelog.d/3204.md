- **PostgreSQL fresh mode writes each recent change about half as many times** (#3204). A table's recent changes were written to disk again in full after every snapshot update and every eight files. A snapshot update now keeps the files already written, and at eight files only the newest small ones are merged. In a synthetic load, rows written per captured change went from 9.89 to 5.53 and the time the keeper held its lock fell by about 30 %; a statement reads about 50 % more small files in exchange. This also fixes a rare case where a table's tail, while being built, could miss a change and answer with an older value. MySQL and MariaDB sources are not affected.
