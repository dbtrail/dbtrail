- **PostgreSQL: every views file pinned to a snapshot reads a table's delta** (part of #2757). The views the console writes on request for a snapshot in S3, `bintrail views` pinned to one, and the views in a snapshot download read a PostgreSQL table's file alone, or refused it, when it was published as its previous file and a delta (`BINTRAIL_PG_TABLE_DELTAS`, off by default). They now find the delta when the file is written (one listing of the snapshot in S3) and name its files exactly. The switch stays off; MySQL and MariaDB views are unchanged, and a listing that fails does not fail them.
