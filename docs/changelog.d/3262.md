- **PostgreSQL port: a WITH's column list is read as PostgreSQL reads it** (#3262). `WITH revenue0 (supplier_no, total_revenue) AS (...)` was taken for a call of a function, so every statement with a WITH column list went to the source, CH-benCHmark's Q15 among them. The copy now answers it, reading each name as the item at its position in the WITH's select list. A list over a `*`, one that names a name twice or a column of a table, and one over a `char(n)` or another column the copy does not hold as PostgreSQL does still go to the source.
