- **PostgreSQL: `infinity` dates no longer read as real dates on the copy** (#2888). A `date` or `timestamp` column holding PostgreSQL's `infinity` or `-infinity` was shown by the copy as `5881580-07-11` (date) or `294247-01-10T04:00:54.775807Z` (timestamp), and the timestamp looks like a value someone stored. The copy held the right value; only its printing was wrong. It now prints `infinity` and `-infinity`, as the source does, on the SQL page, both ports and MCP.
