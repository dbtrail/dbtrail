- **The router's `--concurrency` help says vCPUs, not cores** (#3328). With the number unset the MySQL router runs one statement per two vCPUs, as the Go runtime counts them, so on an Intel instance with two hyperthreads per core that is one per core. The flag help, `docs/option-reference.md` and the sample `dbtrail.cnf` said "two cores". Nothing changes in what the router does.
