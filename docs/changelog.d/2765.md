- **A PostgreSQL-protocol port in the router runs read-only SQL on the copy** (#2765). `bintrail-console router --pg-listen 127.0.0.1:5433` (or `BINTRAIL_ROUTER_PG_LISTEN`) opens it next to the MySQL port: `psql "host=127.0.0.1 port=5433 dbname=<server id or name>"` connects with the MySQL port's password, the access token or a server's application login, and each statement is answered by that server's copy, by PostgreSQL's rules when the source is PostgreSQL. Nothing is sent to the source and a statement that is not a read is refused. This first version sends every column as text, takes the simple query protocol only, serves no time travel, and listens on this machine alone because the password is asked for in clear text and there is no TLS yet. Off unless the address is set. See [SQL on the copy from `psql`](postgres.md#sql-on-the-copy-from-psql).
