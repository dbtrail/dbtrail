### Added

- **Every option of `dbtrail.cnf` on one page** (#2671): `docs/option-reference.md` says, for each of the 129 settings, what it changes, its default, an example line, its environment variable and which programs read it. The same list is an option file with every option explained and commented out (`build/packaging/bintrail-console/dbtrail.cnf`). Both are generated from DBTrail's list of settings, so a setting cannot be added without its words.
