- **MySQL 9.7 LTS is a supported source and index, next to 8.0 and 8.4** (#2884). The MySQL integration suite now runs on 9.7 as a third cell in CI and before every release, with the server's GTIDs turned off as on the other two cells. Percona Server 9.7 is listed with it. The 9.x Innovation releases between LTS lines are not supported. On a 9.7 source the MySQL port used to send every statement to MySQL: 9.7 writes `EXPLAIN FORMAT=JSON` in a new layout by default, which the router does not read, so no statement could be routed to the copy and the reason given was `explain_failed`. The port now asks a MySQL 9 source for the 8.x layout on each connection it opens (`SET SESSION explain_json_format_version = 1`); a client's own `EXPLAIN FORMAT=JSON` through the port shows that layout too. See [the router's plan step](time-travel-sql.md).
