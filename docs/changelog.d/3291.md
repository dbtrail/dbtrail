- **The PostgreSQL port in fresh mode sends to the source what the MySQL router sends to MySQL** (#3291, closes #3116). On a connection with a forwarding user, a statement whose tables' recent changes are not ready after fresh mode's wait, or whose recent changes are older than what an earlier answer of the copy on the same connection read, is no longer answered by the copy with only a notice: it is refused before the copy runs anything, and the source answers it (`copy_too_old` in `/status`). This holds over the simple and the extended protocol, and a connection keeps what it was shown until it closes. A connection with nowhere else to send the statement (a server that hides tables or columns) still gets the copy's answer with the notice, as a MySQL connection that does not route. While a table's recent changes are being gathered (after the router starts, after a snapshot update), statements on it now go to the source.
