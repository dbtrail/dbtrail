- **The web interface shows the installation's database family** (#2815). "+ Add server" now offers the server types of the family the installation serves (MySQL and MariaDB, or PostgreSQL), with a line that says why, and on an installation with no server it says that the first one decides. An installation that holds servers of both families says so under the server list, with their names, for as long as it lasts. On the Connect step the refusal of a server of the other family is no longer followed by "Press Check again once it is fixed", which pressing again could not fix. On an installation that serves PostgreSQL, "+ Add server" opens the full form, since the Connect step adds MySQL and MariaDB servers.
