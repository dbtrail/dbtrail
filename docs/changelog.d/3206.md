- **PostgreSQL fresh mode: a table's recent changes no longer miss a change while they are being built** (#3206). If a table changed while its recent changes were first being loaded, and the other tables had no change at that moment, that change could be left out while the table still reported itself as current. A statement then read the old value of the row, or a row already deleted, until the table's recent changes were next rebuilt or the row changed again. MySQL and MariaDB sources are not affected.
