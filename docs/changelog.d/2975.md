- **PostgreSQL: a snapshot update no longer puts older changes over a full read** (#2775). A full read's rows are the source as of a later position than the one its changes are read from. An update that ran while capture was still behind that position held, for a row changed twice in between, only the first change, and wrote it over the newer row the full read had: the snapshot it published showed that row older, or a deleted row back, until a later update. Such an update now publishes the full read's file as it is.
