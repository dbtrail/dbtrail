- **The PostgreSQL port no longer runs a statement on the copy only to throw its answer away** (closes #3086). On a connection the source already answered about a table, the copy's answer that reads that table is given only when the table was read with its recent changes. A statement whose changes were not ready within fresh mode's wait still ran on the copy from the snapshot alone, and its answer was then discarded and the statement run again on the source: the client paid both, and the copy's worker was held for nothing. The copy is now told before it runs, refuses such a statement the way a routed MySQL statement is refused, and the source answers it at once (`copy_too_old`, as before). Where nothing else can answer (no forwarding account, a server whose rules bar the source), the snapshot answers with its warning, as before.
