### Fixed

- PostgreSQL port: a table or column named like a word the copy keeps for its own SQL (`at`, `by`, `pivot`, `qualify`, `show`, `describe` and the others in docs/postgres.md), written without quotes where a name stands, is quoted before the copy reads it. Those statements used to fail on the copy with a syntax error (or go to the source through a forwarding user); they now answer on the copy as PostgreSQL does, checked against PostgreSQL by `internal/pgcompare`. PostgreSQL's own `GROUP BY`, `ORDER BY`, `AT TIME ZONE` and `SHOW`, and the copy's own `QUALIFY` clause and `ASOF JOIN`, are left alone.
