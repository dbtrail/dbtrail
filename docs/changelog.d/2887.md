- **Docker: the stack serves the PostgreSQL port** (#2887, part of #2774). `docker-compose.yml` gains a `pg-router` service, where PostgreSQL clients read the copy of a PostgreSQL server on port 5433 (`psql "host=127.0.0.1 port=5433 dbname=<server> user=app sslmode=require"`). Like the MySQL port it starts with the stack, is published on this machine only, and listens only while the port for SQL clients is turned on in the web interface; with MySQL or MariaDB servers it waits and uses next to nothing. The installer leaves 5433 unpublished when something else holds it, and says so. **Take the new `docker-compose.yml` when you upgrade** (file version 9): with an older file nothing answers on 5433. docs/docker.md has the settings, including how to serve a certificate clients can verify.
