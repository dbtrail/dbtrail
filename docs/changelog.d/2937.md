### Fixed

- **A connection that was answered with the newest changes is told when a later answer comes from the snapshot alone**, on the MySQL and the PostgreSQL port: a warning on MySQL, a NOTICE on PostgreSQL, "Answered from the snapshot alone, which can be older than an earlier answer of the copy on this connection". It happens when the server is changed from fresh to fast mode while the connection is open, and the answer can then be as old as the last snapshot update. Before, the answer went back in time on that connection with nothing said. It is said once, and again only after the connection has read the newest changes once more; a statement that reads no table (`SELECT 1`, a listing of tables) says nothing.
