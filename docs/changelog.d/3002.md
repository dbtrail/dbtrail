- **PostgreSQL: query history shows rows of tables that are not at REPLICA IDENTITY FULL** (#3002). On a PostgreSQL index, `query` (both binaries), the console's Events page and the MCP `query` tool show such a row for what it is. In JSON the row keeps the markers in its images and gains `"before_image": "key_only"` when PostgreSQL sent only the key of the earlier row, and `"unchanged_columns"` for large values PostgreSQL did not resend. The table format and the console print "(not captured: REPLICA IDENTITY not FULL)" and "(unchanged large value)", and "unknown" for the changed columns of an UPDATE whose earlier row is key-only. A changed-column filter also returns those UPDATEs, live and archived, and says how many "may have changed" the column. Nothing captures such rows yet, so nothing changes in this release, and MySQL output is byte-for-byte the same.
