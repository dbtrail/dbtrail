- **The installer sees the ports Docker holds** (#2831). On Linux, run by a user who is not root, `install.sh` asked `lsof` whether its ports were taken, and `lsof` without privileges does not list the sockets of Docker's own process: every port a container published read as free, and the install died at `docker compose up -d` with Docker's bind error, leaving a folder that failed the same way on a second run. A port is now taken when any probe that can see it says so: `lsof`, the kernel's list of listening sockets (`ss`), or a connection attempt. A taken console port again stops the installer with the command to run instead, taken metrics move to a free port, and a taken MySQL port is left unpublished, as documented.
