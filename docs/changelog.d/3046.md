- **The PostgreSQL port keeps a client's connection to the source between its statements** (closes #3046). It used to open a connection to the source for every statement the source answered and end it before the answer went out, so a cheap read paid a login and the session's settings each time. The connection is now kept for the client's next statement, as the MySQL port keeps its own, and is never held from other clients: when every connection the port may open (`--max-source-connections`) is taken and a client waits for one, the one kept idle longest is ended for it. A kept connection the source ended while idle is opened again for the next statement, without an error.
