### Fixed

- **A PostgreSQL server's "How current SQL answers are" card on the Snapshots page says what the PostgreSQL router applies**, where it showed the MySQL router's state, which does not serve PostgreSQL servers. The web interface reads it from the PostgreSQL router's status, a new setting `--pg-router-url` (`BINTRAIL_CONSOLE_PG_ROUTER_URL`, `PG_ROUTER_URL` in the compose `.env`). The compose stack now starts `pg-router` with its status on `pg-router:9092`, on the compose network only, and points the web interface at it. A stack that sets neither shows the card as it does with no router address: the saved choice, and that what applies cannot be shown.
