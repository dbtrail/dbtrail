- **The web interface says whether capture of a PostgreSQL server is up to date** (#2758). The Overview's capture line answered "PostgreSQL sources are not compared yet" for every PostgreSQL server. It now compares the position the capture saved as sent by the source with how far the source's WAL is flushed, read with one `SELECT`; nothing is installed in the source. Since that WAL moves for the whole cluster and the capture saves its position on a timer, the answer is decided against an earlier read: up to date when a capture that is still saving has reached where the source was then, behind only when a minute later it still has not. The snapshot schedule's own decision for a quiet PostgreSQL server is unchanged.
