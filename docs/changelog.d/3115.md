- **A PostgreSQL full read started by DBTrail copies four tables at once** (#3115). The full read the service starts (the Create button, a schedule, `snapshot run`) gave no number, so it copied one table per CPU of the machine DBTrail runs on, each on its own connection to the source: 32 at once from a 32-core host, a load on the source and a failure where its connection limit is lower. It now copies four at once, as the MySQL full read does. `bintrail-pg baseline --parallelism` is unchanged.
