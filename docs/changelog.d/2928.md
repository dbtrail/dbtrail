- **Iceberg export: `--catalog-scope` for a REST catalog's client credential** (#2928). A client credential is exchanged for a token with the OAuth scope `catalog`, the Iceberg library's default, and there was no way to change it. Apache Polaris refuses that scope (`invalid_scope: The scope is invalid`) and wants `PRINCIPAL_ROLE:ALL`, so a credential alone could not sign in to it, and the way around, a token fetched by hand, is never renewed. `--catalog-scope` (and `ICEBERG_CATALOG_SCOPE` in the compose export services) sets it. It applies only with a client credential; with a bearer token or SigV4, or on a non-REST catalog, it is refused instead of ignored.
