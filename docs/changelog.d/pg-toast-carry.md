- **PostgreSQL: a large value an UPDATE left as it was is taken from the row's earlier change** (part of #2775). Nothing captures such a change yet. For a table that is not at `REPLICA IDENTITY FULL`, PostgreSQL does not send a large value an UPDATE did not touch. A snapshot update and a fresh-mode tail now give the row the value its newest earlier change holds, in whatever order the changes arrive. A value no change since the table's copy holds is refused by name; it is never written as NULL.
