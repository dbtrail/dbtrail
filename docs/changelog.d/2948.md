### Changed

- **The web interface's SQL clients page speaks of the PostgreSQL port when the servers are PostgreSQL** (#2773). The page, its sidebar entry and the command palette say "PostgreSQL clients", its Docs link opens the PostgreSQL client guide, and the MySQL router's numbers are no longer shown there. The memory section says the PostgreSQL port takes a new value when the PostgreSQL router restarts. A PostgreSQL server's hidden tables and columns name the PostgreSQL port, and say that it sends nothing to the source while the server hides something, in place of the MySQL forwarding account's grants check. A MySQL or MariaDB installation sees the page as before.
