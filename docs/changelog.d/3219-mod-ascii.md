- **PostgreSQL port: `mod()` and `ascii()` are answered by the copy** (#3219). `mod(x, n)` stays on the copy when `x` is built of `integer`, `bigint` or `numeric` columns, numbers, `+`, `-`, `*` and parentheses, and `n` is a whole number written in the statement, other than 0 and -1. `ascii()` stays on the copy for a string, a text column or a cut of one, when the first character is below 128; above it the answer depends on the source database's encoding, and PostgreSQL answers. Everything else goes to the source as before. MySQL and MariaDB sources are not affected.
