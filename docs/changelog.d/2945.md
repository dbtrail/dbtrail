- **PostgreSQL: a table delta's files are checked for damage like the table's file** (part of #2757). A snapshot's integrity manifest listed table files and left out the two files of a PostgreSQL table delta (`BINTRAIL_PG_TABLE_DELTAS`, off by default). They are listed now, so a damaged one is refused when a snapshot update would carry it into the next snapshot, where before it was carried under a clean manifest. The switch stays off; a MySQL or MariaDB snapshot's manifest is unchanged.
