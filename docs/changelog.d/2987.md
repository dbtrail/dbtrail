- **PostgreSQL: a table taken out of the publication, or dropped, is noticed** (#2775). PostgreSQL's change stream says nothing when a table leaves the publication: it stops carrying it. Its snapshot file was then carried from update to update as a table with no change and its fresh-mode tail, empty, taken for up to date, so statements were answered with the table as it was the day it left, with nothing to say so. Capture now compares the publication's tables at each reading of the source's health with the reading before (kept across restarts), records a table that is gone in `schema_changes`, and an update refuses to build on its snapshot: the next full read no longer holds the table.
