- **PostgreSQL table deltas: a table whose delta has ended is written from its file and that delta** (#2775). When a delta grew past its share of the table, or its file grew too old, the table was written in full by reading again, from the index, every change since its file was written: hours of them. On the 200-warehouse rig one such update took 6 minutes where the others took 80 seconds, the scheduler took it for what updates cost and fell back to a full read of the source. The table is now written from the file and the delta beside it, with only the changes since that delta read from the index.
