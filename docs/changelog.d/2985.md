- **The PostgreSQL port sends to the copy only what is expensive on the source** (#2985). With a forwarding user, every statement the copy answers as PostgreSQL does went to the copy, reads by a primary key included; the copy has no index, so `SELECT ... WHERE id = $1` on a table of 2 million rows took 15 seconds there, queued behind one worker, against about a millisecond on PostgreSQL. The port now asks the source for the statement's plan first (`EXPLAIN (FORMAT JSON)`, `GENERIC_PLAN` for a prepared statement with parameters) and sends it to the copy only when the plan's Total Cost is 50,000 or more, or a sequential scan in it is estimated at 1,000,000 rows or more; otherwise the source answers it (`cheap_plan` in `/status`). An `EXPLAIN` the source refuses sends the statement to the source, which answers with its own error (`explain_failed`). The thresholds are `--cost-threshold` and `--scan-rows` of `pg-router` (`BINTRAIL_PG_ROUTER_COST_THRESHOLD`, `BINTRAIL_PG_ROUTER_SCAN_ROWS`; `PG_ROUTER_COST_THRESHOLD` and `PG_ROUTER_SCAN_ROWS` in the compose `.env`). On PostgreSQL 15, which has no `GENERIC_PLAN`, a prepared statement with parameters goes to the source. Measured under 50 clients, two things this needed are part of it. A statement that finds the port's connections to the source all taken (`--max-source-connections`, 16) now waits for one to be given back, up to 30 seconds or its `statement_timeout`, as a statement waits in line for the copy; before, it was refused at once with `53300`, which 92% of the bench's statements got. And a connection the source answered is not given an answer of the copy older than that: the copy, a second or two behind, read a counter go back (37413, then 37405) on one connection. The copy's answer is given only when its recent changes reach past the source's last answer on that connection; otherwise the source answers (`copy_too_old` in `/status`), and a table read from its snapshot alone goes to the source on such a connection. A connection also remembers the source's verdict on a statement shape for a minute, when every value in it is compared with `=` and the plan is ten times from the thresholds, so a read by key with another key is not asked about again.
