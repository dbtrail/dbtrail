- **PostgreSQL: a snapshot's views file in S3 reads a table's delta** (part of #2757). The `views.sql` published with a snapshot read a PostgreSQL table's file alone when its files were named in S3, so a table published as its previous file and a delta (`BINTRAIL_PG_TABLE_DELTAS`, off by default) showed as it was at an earlier update. The file is now written knowing what is beside each table's file, and names the delta's files by their exact keys: nothing is listed when it is read. The copy with relative paths reads the delta too. The switch stays off; MySQL and MariaDB views are unchanged.
