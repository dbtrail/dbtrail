- **PostgreSQL: the views file published with a snapshot in S3 reads a table's delta** (part of #2757). The `views.sql` published with a snapshot read a PostgreSQL table's file alone when its files were named in S3, so a table published as its previous file and a delta (`BINTRAIL_PG_TABLE_DELTAS`, off by default) showed as it was at an earlier update. The file is now written knowing what is beside each table's file, and names the delta's files by their exact keys: nothing is listed when it is read. A views file the console or `bintrail views` writes for a snapshot in S3 still reads the file alone. The switch stays off; MySQL and MariaDB views are unchanged.
