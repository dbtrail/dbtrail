- **Fresh mode: a table a chain-ending refresh rewrote without changes keeps its tail** (#3306). A refresh that ends delta chains for age rewrites every table at its cut, including tables with no change since their last full read. Those tables' lookups started from that read, or from a last change carried forward from long ago. Once rotation had dropped that hour, the table had no tail, and every statement touching it read all tables as of the snapshot until the next refresh: answers were several minutes stale for a few minutes after each such refresh (about 8 minutes observed). A table whose own cut is its directory's refresh cut now starts its lookup at that refresh's mark, as a table carried below it already did. Fast mode's "unchanged since the snapshot" check gets the same fix.
