- **Two web interfaces on one machine keep their own login** (#2833). The login cookie was named `bintrail_session` for every address, and a browser does not tell the ports of one host apart: with two installations on one machine (on 8090 and 8091), signing in to one overwrote the other's login, and signing out of either signed out of both. The cookie's name now carries the port the browser opened (`bintrail_session_8091`). A login made before this version keeps working; a login through an installed provider is named for the port too. Signing out ends every session the browser holds for that address, and leaves alone a cookie under the old name that belongs to another console on the host. Behind a proxy on the default port the name is unchanged.
