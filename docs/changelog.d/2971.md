- **PostgreSQL: a full read's files record how far back the changes after them reach** (#2775). The first snapshot update after every full read of a PostgreSQL source wrote every table again in full, changed or not, because the file a full read writes did not record that bound and a file without it is neither carried into the next snapshot unchanged nor given a table delta. It records it now: the instant a reader already assumed. A table nothing wrote to is carried from the first update on.
