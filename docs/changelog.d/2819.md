- **Fresh mode: a second process on the same machine no longer removes a running one's tail files** (#2819). At its start, a process that keeps tails removed every `bintrail-tails-*` directory of its user that had not been written for 30 minutes. A running process writes only when a tail changes, so one whose server had no captured change for that long lost its files to the other's start, and its statements were then handed files that were gone. Each process now holds a lock on its own directory for as long as it may be read, and the start-up cleanup removes only directories no running process holds (and, as before, not written for 30 minutes). A process whose directory is removed anyway, by hand or by an older version, logs a warning, makes the directory again and builds its tails again from the index.
