### Added

- **The PostgreSQL port's status says how old each server's answers were** (#2756). `/status` of `pg-router` now gives, per server, `data_as_of` (every change capture had recorded up to that instant was in what the last answer read), `data_age_seconds` (how long before the answer that was), and `data_age_max_seconds` (the worst since the process started), the MySQL router's fields. Only an answer the client got counts. An answer that read a table without its newest changes (fast mode, among others) has no age: `data_age_unknown` counts them and `data_age_unknown_reason` says why, since how far a PostgreSQL snapshot reaches is not recorded yet. On a source with no write since, the age grows though nothing is missing.
