- **PostgreSQL: groundwork for capturing tables that are not at REPLICA IDENTITY FULL** (#2998). The index gains a marker for a column of an earlier row that PostgreSQL did not send, the read side refuses undo over such a change with a message that names the table, the row and the columns, and says that `ALTER TABLE ... REPLICA IDENTITY FULL` makes later changes undoable, and the changed-columns list of such an UPDATE is stored as unknown rather than guessed. Nothing produces the marker yet: no behaviour change in this release, and none at all for MySQL.
