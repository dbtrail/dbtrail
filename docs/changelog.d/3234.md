- **In fresh mode, a statement over tables that already have recent changes to read no longer waits for an update of them** (#3234). Every statement on the MySQL and PostgreSQL ports waited for any update of the copy's recent changes that was running, however long it took. It now goes on at once and reads the last version published, with the same rows; with an update held for 4 s, a report went from 4 s to under 65 ms. A table with no version yet still waits for the running update, for at most half of the statement's time limit, and then goes the normal way: your database answers it, or the copy does and says it read the snapshot alone.
