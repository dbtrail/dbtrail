- **PostgreSQL router: a status line a minute in its log** (#3035, part of #3021). `docker compose logs -f pg-router | grep msg=status` (or `journalctl -u bintrail-pg-router -f | grep msg=status`) used to show nothing. It now shows one line per PostgreSQL server each minute: `msg=status service=pg-port server=shop interval=1m0s queries=124 dbtrail=110 postgresql=12 refused=2 errors=2 dbtrail_avg_ms=420 postgresql_avg_ms=30 copy_behind_s=45`. The numbers are the interval's, a quiet minute still writes a line, and `BINTRAIL_STATUS_LOG_INTERVAL` (`STATUS_LOG_INTERVAL` in `.env`) sets the interval or turns it off, as for the other services.
