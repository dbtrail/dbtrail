- **A statement Engine Routing forwards to MySQL returns MySQL's own text for `FLOAT`, `DOUBLE` and `ZEROFILL` cells** (#2828). The port read each row of a forwarded answer as numbers and printed them again on the way out, in its own form rather than MySQL's: a `FLOAT` holding `1e38` reached the client as `1` followed by 38 zeros, `1e-38` as `0.` and 37 zeros and a `1`, a `FLOAT(7,2)` `0.10` as `0.1`, `1.00` as `1`, and an `INT(5) ZEROFILL` `00042` as `42`. No error was raised. Every cell of a forwarded text answer is now the bytes MySQL sent (checked on MySQL 8.0 against the `mysql` client for `FLOAT`, `FLOAT(M,D)`, `FLOAT UNSIGNED`, `DOUBLE`, `DOUBLE(M,D)`, `ZEROFILL`, large, small, negative, `NULL` and `-0` values, and expressions over them). Prepared statements were not affected: their answer is binary and already carried MySQL's own values.
