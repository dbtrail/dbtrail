- **`bintrail upload` sends a PostgreSQL table's delta with its file** (part of #2757). For a table published as its previous file and a delta (`BINTRAIL_PG_TABLE_DELTAS`, off by default), the upload sent the table's file and left the delta's two files behind: the uploaded snapshot held the table as it was at an earlier update. Both files are now sent, before the table's file. The switch stays off; what is sent for MySQL and MariaDB is unchanged.
