- **PostgreSQL: fresh mode is wired, and no process turns it on yet** (part of #2756). A PostgreSQL server now gets the tail of its tables' recent changes in a process that asks for it, so a statement on its copy reads what capture has indexed up to its last saved position, not only its last snapshot. Nothing asks yet: the PostgreSQL port still answers as of the last snapshot update until it does. It is turned on by the process, not by a setting, because a PostgreSQL key is text and the tail is exact only where a statement runs by PostgreSQL's rules. MySQL and MariaDB servers are unchanged.
