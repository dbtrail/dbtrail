- **PostgreSQL table deltas: an update reads only the changes since the one before** (#2775). With `BINTRAIL_PG_TABLE_DELTAS` on, every snapshot update read every change since the table's file was written again from the index and wrote the delta again from them, so each update cost more than the one before. An update now reads the changes since the previous delta ended and writes the new delta from that one and them. When the previous delta cannot be continued, the changes are read from the file's start, as before. The switch stays off by default.
