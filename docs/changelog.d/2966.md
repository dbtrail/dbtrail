- **PostgreSQL: fresh mode waits for capture before it lays changes over a full read** (#2963). A full read's snapshot holds the source as of a moment a little after the point its changes are read from. If capture was behind that moment when the snapshot was published, a row that had changed twice in between showed its first change over the second, which the snapshot held: an older value, or a deleted row back, with no notice, until capture caught up. A full read now records that moment, and a table's recent changes are not laid over it until capture has passed it. Rare (capture has to be behind for as long as the full read takes), and silent when it happened.
