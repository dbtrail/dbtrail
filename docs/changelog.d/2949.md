### Changed

- **The web interface's Connect screen offers the way to a PostgreSQL** (#2773). It opens the full form with PostgreSQL picked and the probed host and port filled in, without the MySQL account the screen suggests. An installation that serves MySQL and MariaDB is offered nothing new.
