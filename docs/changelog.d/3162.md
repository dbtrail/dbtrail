- **The router limits how many clients are connected to the MySQL port, and gives a client 30 seconds to log in** (#3162). The port took any number of connections, and one that never logged in stayed for as long as it liked: only the machine bounded them. Now at most 256 clients are connected at once; one more is refused before the handshake with MySQL error 1040, "Too many connections", as a MySQL server at its `max_connections` answers. `--max-connections` (`BINTRAIL_ROUTER_MAX_CONNECTIONS`, 1 to 1024) changes the number. A connection that has not logged in after 30 seconds is closed. These are the PostgreSQL port's numbers. If a pool keeps more than 256 connections to the router, raise the limit or lower the pool's maximum when you upgrade. The MySQL port inside `watch` keeps no client limit, and gets the 30 seconds.
