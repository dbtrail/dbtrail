- **Engine Routing reads `DATEDIFF` and `DATE_FORMAT` with a vertical tab before the parenthesis as the calls they are** (#2802). MySQL takes a space and the bytes 0x09 to 0x0D between a function's name and its parenthesis. With a vertical tab there, `DATEDIFF('2026-01-15 02:00:00+05:00', d)` went to the copy, which read the string's date as written and answered a day off MySQL (-45 where MySQL answers -46), where with a space it stays on MySQL. The routing port's checks now take the same white space MySQL takes, through one shared pattern that the `ROUND`, `LEFT`/`RIGHT`, `SUBSTRING` and `CONCAT`/`LEAST`/`GREATEST` checks already followed. The port without routing is unchanged.
