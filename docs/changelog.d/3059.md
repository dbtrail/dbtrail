- **PostgreSQL port: `\dt`, `\d <table>` and `\l` are answered for psql 13 to 18, not only 16** (#3059). Each major version of psql writes these commands as catalog statements of its own, and the port recognized psql 16's. With psql 14.25, the one Ubuntu 22.04 installs, `\dt`, `\d <table>`, `\d+ <table>` and `\l` were refused as "this statement reads the system catalog"; the same with psql 13; psql 18 was refused `\d <table>` and `\l`, and psql 15 and 17 `\l`. The port now recognizes what each of psql 13.23, 14.25, 15.20, 16.16, 17.12 and 18.7 sends for `\l`, `\dn`, `\dt`, `\d`, `\d <table>` and `\d+ <table>`, and tells each the same of the copy: the same schemas, tables, columns and primary keys, and nothing the server hides. A catalog statement none of them sends is refused as before.
