- **PostgreSQL fresh mode: a large table keeps its newest changes for longer before falling back to the snapshot** (#3013, part of #2775). A table's tail was dropped past 500,000 changed keys since its snapshot, however much of the tails' memory was free, and the table then answered from the snapshot until the next update. For a PostgreSQL server the default is now 2,000,000 keys when the tails' memory is bounded (`BINTRAIL_SQL_TAIL_MAX_BYTES`, a fifth of the process's memory unless set), so the memory bound is what holds them. A value you set is used as it is; MySQL and MariaDB servers keep 500,000.
