- **PostgreSQL: a table nothing writes to no longer makes every snapshot update fail** (#2775). DBTrail learns a PostgreSQL table's shape when the first change of it arrives, so a lookup table that never changes had none. A snapshot update refused such a table ("not found in any schema snapshot"), published nothing, and a full read of the source followed, at every update: on a 97-million-row database, 7 minutes of work thrown away and then the whole source read, every cycle. And in fresh mode every statement that joined such a table was answered from the snapshot alone. Both now take the table's shape from its own snapshot file.
