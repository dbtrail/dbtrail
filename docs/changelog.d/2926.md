- **PostgreSQL: the reader of a table's recent changes, not in use yet** (part of #2756). The second part of fresh mode for a PostgreSQL source: it reads a table's changes from the index from its snapshot's LSN, up to the position capture last saved and no further, so half a transaction is never read, and it ends a table's tail when the table's shape changed, capture recorded a loss, or the index no longer holds every hour since the snapshot. Nothing builds it yet, so a PostgreSQL copy still answers as of its last update.
