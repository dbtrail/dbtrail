- **Engine Routing: a statement that reads a `FLOAT` column is answered by MySQL** (#2827). MySQL compares and computes a `FLOAT` as a double, and the copy as a single-precision float, so the copy could answer such a statement with other rows or values than MySQL, without an error: `WHERE f = 3.14` found the row on the copy where MySQL finds none (3.14 stored in a `FLOAT` is 3.140000104904175), `MIN(f * 2)` near the type's limit was `-Infinity`, and `GROUP BY f` could merge two values a dump prints alike. Under routing, a statement that names a `FLOAT` column, or has a star over a table with one, now goes to MySQL; a statement over the same table that does not name the column is still answered by the copy. The port without routing still answers from the copy.
