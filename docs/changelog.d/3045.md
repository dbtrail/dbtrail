- **A PostgreSQL statement whose plan cost sits near the routing threshold no longer changes side on its own** (closes #3045). A shape whose estimate moved a little across 50,000 went from the source to the copy, where the same lookup took seconds each. The port now remembers, per server and across its connections, which side each statement shape was last sent to by its plan, and keeps it there while the plan stays within 10 % of the threshold: to the copy only past 55,000, back to the source only under 45,000 (the scan rule's 1,000,000 rows likewise). The plan is still asked for every statement. A change of side is logged.
