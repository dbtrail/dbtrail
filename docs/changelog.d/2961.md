- **PostgreSQL: a snapshot update no longer slows down with the age of the index** (#2775). To update the copy, DBTrail read each table's changes from up to two hours before the previous snapshot and dropped the older ones row by row. On an install that had run for a few hours, on a busy source, that took minutes for every table: a 200-row table took 79 seconds to update, and a whole update 17 minutes where it had taken 7 on a new index. It now reads from the previous snapshot's own bound. MySQL and MariaDB are not changed.
