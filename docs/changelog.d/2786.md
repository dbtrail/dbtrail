- **SQL on the copy of a PostgreSQL source sorts NULL, divides integers and compares text as PostgreSQL does** (#2786). The engine's session was the one written for MySQL on every server, so on a PostgreSQL server `ORDER BY qty` put NULL first where the source puts it last, `9 / 2` answered `4.5` where the source answers `4`, and `'a' = 'A'` was true for text with no column behind it; none of them with an error. In the console's SQL card and the `sql` tool, a statement on a PostgreSQL server now runs with NULL as the largest value, `/` between two integers cut toward zero, and text compared byte by byte. A MySQL or MariaDB server's session is unchanged. A division by zero is still NULL where PostgreSQL fails the statement: the engine has no setting for it. See [how each type reads](postgres.md#how-each-type-reads-in-sql-on-the-copy).
