- **Docs: what a rule that hides a column does not reach on a PostgreSQL connection that is already open** (#3074). `docs/postgres.md` and `docs/console.md` now say both cases: the rest of a result the client had already asked for still carries the column, and the column's name can stay in that connection's catalog listing for up to 10 seconds (reading the column already fails). `docs/console.md` said "a couple of seconds".
