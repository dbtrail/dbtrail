- **PostgreSQL: a table with a delta beside its file answers in fresh mode too** (part of #2757). A table published as its previous file and a delta (`BINTRAIL_PG_TABLE_DELTAS`, off by default) had no recent changes laid over it on the PostgreSQL port, and neither did any statement that read it. It has now: the changes captured since its file was written lie over the file and its delta. The switch stays off.
