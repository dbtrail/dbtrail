- **An installation serves one database family: MySQL and MariaDB, or PostgreSQL** (#2815). The first server added decides which; a server of the other family is refused, in the web interface and from `dbtrail server add`, with a message that says what the installation serves, that nothing was changed, and to run a second installation for the other family (`DBTRAIL_DIR=./dbtrail-postgres DBTRAIL_PORT=8091` on the installer). The two families were never run together in one process by any test, so the combination is no longer offered. A servers file that already holds both (edited by hand, or from before this version) stops nothing: every server is still captured and served, an error in the log names them, and no server can be added or edited until one family is left. This is about the databases captured from; the index is MySQL for every family. There is no setting that allows the mix. See [One database family per installation](install.md#one-database-family-per-installation).
