- **Iceberg export: `--catalog-access-delegation none` for a REST catalog with no storage credentials to vend** (#2929). Every request asked the catalog for vended credentials, and a catalog set up with none to give refused the table: Apache Gravitino's Iceberg REST server with no credential provider (`No credential provider found for path s3://...`) and Apache Polaris with `stsUnavailable` (`Credential vending was requested ... but no credentials are available`). With `none` (or `ICEBERG_CATALOG_ACCESS_DELEGATION=none` in the compose export services) no request asks, and the files are written with the machine's own AWS credentials. The default is unchanged. Refused with `--catalog-sigv4`, and `remote-signing` is refused by name.
