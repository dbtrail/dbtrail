- **PostgreSQL: a snapshot update and a fresh-mode tail take a change whose earlier row was captured with its key only** (#2775). Nothing captures such a change yet; this is the reading side of capturing tables that are not at `REPLICA IDENTITY FULL`, which PostgreSQL sends the earlier row's key of, and nothing else. A fold builds the table from the row each change leaves and never reads the rest of the earlier one. It still refuses a row after the change with a column that was not captured, an earlier row with no key, and an unchanged large value.
