- **PostgreSQL table deltas: a table whose delta has ended is written in seconds** (#2775). Writing such a table in full passed every row of it through the daemon: minutes for a table of tens of millions of rows, long enough to miss the next update. The engine that reads the files now writes the new file from the table's file and its delta, as it already does when MySQL deltas are compacted; the row-by-row way remains for a window that went to disk, one that lost captured changes, and when the engine cannot.
