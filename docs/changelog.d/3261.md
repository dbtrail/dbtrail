- **PostgreSQL port: a name given inside a table in FROM or a WITH is read by the copy in the WHERE around it** (#3261). The port sent to the source every statement whose WHERE named an alias of any select list, so CH-benCHmark's Q2, which filters on `m_i_id` and `m_s_quantity` of its table `m`, ran on the source. Now only a name read by the same statement that gives it, by a subquery of it or by a statement beside it goes to the source, where PostgreSQL refuses it. A name given to a `char(n)` or to another column the copy does not hold as PostgreSQL does still goes to the source wherever it is read, and `WHERE id IN (SELECT ...) AND q > 2` is now checked after the subquery too.
