- **Time travel through `pg-router`** (#2765). A PostgreSQL client connected to `bintrail-console pg-router` can ask for one row as it was at a past moment (`SELECT * FROM _flashback.orders AS OF '5 minutes ago' WHERE id = 42`, and `_snapshot`), on the same connection that runs SQL on the copy; it was refused there. A server that hides rows or columns refuses it with the reason, since time travel reads the history past the views that hide them. A whole table as of a moment is still refused on this wire. Each answer leaves the time-travel audit record.
