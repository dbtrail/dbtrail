- **Time travel on the PostgreSQL port can read a server's S3 destination under Docker** (#3142). The `pg-router` service was given no S3 variable, so a `_snapshot` query for a moment older than the snapshots in the local folder failed for lack of credentials unless the machine had a role. It now gets the same `AWS_*`, `BINTRAIL_S3_ENDPOINT` and `BINTRAIL_S3_PATH_STYLE` as the other services (compose file version 13), and can have read-only keys of its own with `PG_ROUTER_AWS_ACCESS_KEY_ID`, `PG_ROUTER_AWS_SECRET_ACCESS_KEY` and `PG_ROUTER_AWS_SESSION_TOKEN`, by the rules of the MySQL router's `ROUTER_AWS_*`: its own pair never carries the shared token, and half a pair is refused at start. With the packaged unit, an empty `AWS_SESSION_TOKEN=` in the service's own environment file is dropped at start, as for `bintrail-router`.
