- **PostgreSQL fresh mode: the newest changes of a table take a third of the memory** (#2775). A table's tail held every changed row as the map its change arrived with, about 1.5 KB a row for rows of a hundred bytes. On a source written to all the time the tails passed their memory budget minutes after each snapshot update, stopped advancing, and statements were answered as of the snapshot. Each row is now held as one run of bytes.
