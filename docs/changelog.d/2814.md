- **A regression gate for a MySQL source's answers on the copy** (#2814). The views over the copy, the way a column is cast and the session a statement runs in are shared by every source family, so work for one family edits code the others read through. A new test (`internal/mysqlgate`) converts a fixed MySQL dump the way the product does, runs a fixed list of statements through the real views and the real SQL worker, and compares every answer (column names, types and cells) byte for byte with the reviewed ones in `testdata/answers.golden.txt`. It needs no database, so it runs in the unit tests of every pull request. A change that alters a MySQL answer on purpose changes that file in the same pull request, where the difference is reviewed. No product behaviour changes.
