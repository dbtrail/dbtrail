- **The MySQL port without Engine Routing refuses `DATEDIFF` of a string with a UTC offset** (#2790). `DATEDIFF('2026-01-15 02:00:00+05:00', d)` was answered by the copy with the date as written, a day off from MySQL, which moves the time into the connection's time zone first (and reads `NULL` for an offset it does not take, such as `+0500` or `-00:00`). It is now refused with error 1235, as text and as a prepared statement, and the refusal gives the copy's spelling that answers MySQL's number: `date_diff('day', CAST(b AS DATE), CAST(CAST(a AS TIMESTAMPTZ) AS DATE))`. Strings MySQL reads no offset in (a trailing `Z`, a space before the offset) are answered as before. A text column holding an offset is still read the copy's way on this port; docs/time-travel-sql.md says so. Engine Routing is unchanged: it already sends every `DATEDIFF` of a string to MySQL.
